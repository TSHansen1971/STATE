## Nature

This is a **non-normative operational template**.

It is a reusable physical representation of existing STATE semantics.

**Canonical mapping:** WP-11 Deviation and Escalation Record

The template name does not create a new Work Product class.

## Template

```text
deviation_identity:
transition_identity:
candidate_or_phase:
discovered_by:
discovery:
current_boundary:
classification: INSIDE / OUTSIDE / UNCERTAIN
authority_available:
action_taken:
implementation_performed: YES / NO
escalation_target:
evidence_reference:
resolution:
```

Discovery does not expand scope.
