## Nature

This is a **non-normative operational template**.

It is a reusable physical representation of existing STATE semantics.

**Canonical mapping:** WP-08 Acceptance Record

The template name does not create a new Work Product class.

## Template

```text
acceptance_record_identity:
transition_identity:
candidate_identity:
acceptance_basis_reference:
verification_record_references:
evidence_set_reference:
required_claim_status:
known_negative_evidence:
known_residual_uncertainty:
decision: ACCEPT / REJECT / REPAIR REQUIRED / INCONCLUSIVE
acceptance_authority:
authority_basis:
decision_rationale:
decision_time:
next_action:
```

Acceptance does not rewrite Verification and does not itself perform P9 Baseline Establishment.
