The Conceptual layer defines what STATE Engineering is independently of any particular workflow implementation or toolchain.

Its governing question is:

> **What concepts and relationships must exist for a controlled STATE transition to be described unambiguously?**

This layer contains the state model, foundational properties, authority concepts, actor model, evidence concepts and secure-engineering foundation.
