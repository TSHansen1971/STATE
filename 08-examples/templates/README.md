## Purpose

This directory provides copyable, non-normative starting points for applying existing STATE semantics.

Templates implement or physically represent existing logical obligations.

They do **not** create new Work Product classes through naming alone.

## Templates and canonical mapping

| Template | Canonical relationship |
|---|---|
| Transition Charter | WP-01 + WP-05 physical representation, referencing WP-02/WP-03/WP-04 |
| Authority Grant | WP-02 |
| Actor Assignment | WP-03 |
| Acceptance Basis | WP-01 / Transition Contract information used by WP-08 |
| Verification Record | WP-06 |
| Evidence Manifest | physical index for WP-07 |
| Boundary Deviation Record | WP-11 |
| Repair / Resumption Record | WP-05 + WP-11 where material |
| Acceptance Decision | WP-08 |
| Tailoring Record | existing Tailoring Decision fields; not a Work Product class |
