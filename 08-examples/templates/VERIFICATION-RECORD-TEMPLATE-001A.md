## Nature

This is a **non-normative operational template**.

It is a reusable physical representation of existing STATE semantics.

**Canonical mapping:** WP-06 Verification Record

The template name does not create a new Work Product class.

## Template

```text
verification_record_identity:
transition_identity:
candidate_identity:
claim:
claim_target:
method:
environment:
observation:
evidence_references:
result: PASS / FAIL / INCONCLUSIVE
limitations:
independence_basis:
performed_by:
performed_at:
```

PASS remains bounded to the stated claim, target, method and conditions.
