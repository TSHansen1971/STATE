## Nature

This is a **non-normative operational template**.

It is a reusable physical representation of existing STATE semantics.

**Canonical mapping:** physical index/manifest for WP-07 Evidence Set

The template name does not create a new Work Product class.

## Template

```text
evidence_set_identity:
transition_identity:
candidate_identity:
items:
  - evidence_item_identity:
    claim_reference:
    type:
    source:
    provenance:
    integrity_or_digest:
    environment_reference:
    preserved_location:
    limitations:
negative_evidence:
residual_gaps:
```

An Evidence Manifest indexes Evidence; it does not create a new Evidence or Work Product class.
