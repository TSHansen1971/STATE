## Purpose

This directory is the stable repository namespace for illustrative STATE Engineering examples.

Examples are non-normative unless a future document explicitly states otherwise under authorized method governance. Content placed here may demonstrate existing STATE semantics but does not create new lifecycle phases, Transition Gates, Authority Domains, logical Roles, Work Product classes or Conformance Requirements.

The complete worked STATE Transition planned for v1.1.0 WP08 belongs in this namespace.

## Namespace boundary

The repository reserves:

- `08-examples/` for illustrative examples;
- `09-releases/` for release records and authorized public release evidence;
- `10-development/` for method-development history, epics and controlled planning material.

Repository paths are treated as durable public identifiers after publication and shall not be casually renumbered or repurposed.
